# Provenance and Publication Boundary

## Historical Background

PCSpeedAPP was completed in 2023 as a PAP project for a Management Informatics vocational course. It addressed computer-repair and technical-support workflows in the context of PCSpeed, an IT services company in Viseu, Portugal.

The project was not developed entirely from an empty codebase. PGOSTEC, an existing internal application developed by Dário, was supplied for educational support and used as a technical foundation. The resulting academic project combined inherited material with student analysis, adaptation, workflow changes, interface work, database work, testing, and project delivery.

## Why the Complete Source Is Private

No written authorization for public redistribution of the PGOSTEC source is currently documented. The historical project contains a mixture of original code, modified inherited code, third-party components, and assets with different ownership or licensing conditions.

A reliable line-by-line authorship boundary cannot be established automatically several years later. A generated diff would show textual differences but would not prove that every resulting line is independently redistributable.

For those reasons, this public showcase excludes the complete historical source tree.

## Public Material

This showcase is limited to:

- Portfolio documentation written specifically for public presentation.
- High-level descriptions of features and architecture.
- Fully anonymized screenshots, if added after manual review.
- Independently written code samples, if added after a separate provenance review.

It must never include credentials, database backups, logs, personal records, private notes, supplied archives, or unreviewed historical source files.

The complete historical implementation is private and is not offered for download, reuse, or redistribution. This restriction does not diminish the student's academic contribution; it records the contribution honestly while respecting uncertain third-party rights and confidentiality.
