# Screenshot Publication Checklist

Screenshots can make the portfolio more useful, but every image must be reviewed manually before it is added.

## Required Checks

- Use fictional data created specifically for the screenshot.
- Remove names, addresses, phone numbers, email addresses, serial numbers, and repair notes belonging to real people.
- Remove usernames, passwords, API keys, database names, internal URLs, and server paths.
- Remove browser bookmarks, notifications, account avatars, and operating-system details.
- Avoid showing private company statistics or internal operational information.
- Review image metadata before publication.
- Prefer recreating the screen with fictional records instead of blurring real data.

## Suggested Gallery

Safe screenshots could demonstrate:

1. Login screen with fictional credentials hidden.
2. Main dashboard or navigation.
3. Fictional customer list.
4. New repair-order form using invented details.
5. Repair-order status workflow.
6. Printable service summary with fictional information.
